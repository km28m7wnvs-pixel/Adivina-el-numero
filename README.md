# Nombre del proyecto

Adivina el Número

# Integrante

Isabel Guaicha

# Objetivo del sistema

Desarrollar un juego de consola en Python que permita al usuario adivinar un número aleatorio entre 1 y 100, teniendo un máximo de siete intentos por partida. El sistema permite realizar varias partidas, acumular puntos y consultar el historial de las partidas realizadas.

# Descripción de funcionalidades

El juego "Adivina el Número" genera aleatoriamente un número entre 1 y 100 para que el jugador intente adivinarlo.

El jugador dispone de un máximo de siete intentos por partida. Después de cada intento, el sistema compara el número ingresado con el número secreto y proporciona una pista indicando si el número secreto es mayor o menor.

Si el jugador adivina el número dentro de los siete intentos, gana la partida y obtiene 10 puntos. Si no logra adivinarlo después de los siete intentos, pierde la partida y el sistema muestra el número secreto.

El sistema permite jugar varias partidas durante la ejecución del programa y mantiene una puntuación acumulada.

El juego también cuenta con un historial de partidas, donde se registra:

- Número de partida.
- Resultado de la partida.
- Cantidad de intentos utilizados.
- Puntos obtenidos.

El programa dispone de un menú principal con las siguientes opciones:

1. Jugar.
2. Ver puntuación.
3. Ver historial.
4. Salir.

El código está organizado mediante funciones y se divide en los archivos `main.py` y `funciones.py`, permitiendo mantener el programa estructurado y facilitar su funcionamiento.
