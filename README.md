# Juego: Adivina el Número

## Descripción

Este proyecto consiste en desarrollar un juego en Python llamado **Adivina el Número**.

El programa genera un número aleatorio entre 1 y 100 y el jugador debe adivinarlo. En cada intento, el programa indica si el número secreto es mayor o menor hasta que el jugador lo encuentre.

---

## Objetivo

Aplicar los conocimientos adquiridos sobre:

- Variables
- Estructuras condicionales (if, elif, else)
- Estructuras repetitivas (while)
- Diagramas de flujo
- Uso de Git y GitHub

---

## Entradas

- Número ingresado por el usuario.

---

## Procesos

- Generar un número aleatorio.
- Comparar el número ingresado con el número secreto.
- Contar los intentos realizados.
- Mostrar pistas al usuario.
- Repetir el proceso hasta adivinar el número.

---

## Salidas

- Mensajes indicando si el número secreto es mayor o menor.
- Mensaje de felicitación.
- Número total de intentos.
